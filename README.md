# Portafolio · José Meza

Portafolio bilingüe (ES/EN) hecho con Next.js, TypeScript y Tailwind CSS.

- Contenido editable en `content/` (`projects.ts`, `experience.ts`, `i18n/`).
- `npm run dev` para desarrollo y `npm run build` para producción.
- Define `NEXT_PUBLIC_SITE_URL` (por ejemplo `https://tu-dominio.vercel.app`) para el sitemap y las metaetiquetas.
